This is the collection of all Software Development Project I did in SMU Guildhall.
All of the projects are made by my custom SMU Guildhall Game Engine
All Codes can be found in the code folder.
The program can be opened by running the exe file within the Run folder

As of now it includes:
1. Starship, a 2d space shooter
2. Project Libra, a 2d tank game with collision and map generation
3. Doomenstein, a Doom Clone
4. Chess 3D, Chess with 3D rendering
5. Simple Miner, Minercraft world generator
6. Math Unit and Visual Test
7. Cube Chaos Clone, a simplified clone of the Indie game Cube Chaos
8. Protogame 2D RPG, My Thesis Project, a 2D Procedural Dungeon Generator
